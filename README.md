# Light Times Overlay

A browser extension that shows golden hour, blue hour, sunrise, and sunset
times for the location currently open in Google Maps.

## Features

- Reads a place pin, search result, or map view from the active Google Maps tab
- Shows today's light phases in a compact timeline
- Displays local times using the location's time zone

## Planned expansions

- **Choose a location manually** when the active tab is not Google Maps
- **Show the next day's times** for planning around sunrise and sunset
- **Add a settings view** for time format and location privacy preferences
- **Improve location feedback** with clearer permission and unavailable-location states
